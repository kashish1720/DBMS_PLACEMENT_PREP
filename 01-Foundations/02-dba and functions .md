# Database Administrator (DBA)

## Definition
**DBA** woh professional hai jo database system ki **installation, configuration, maintenance aur security** sambhalta hai. Yeh ensure karta hai ki data hamesha **available, consistent, secure aur recoverable** rahe.

**Example:** Library mein librarian ki tarah, jo dekhta hai kaun kya le sakta hai aur kitaab kho jaaye toh kya karna hai.

## Main Responsibilities

| Role | Kaam |
|---|---|
| Installation & Configuration | DBMS install aur servers set up karna |
| User Management & Security | Users, roles, privileges, encryption |
| Performance Tuning | Queries optimize, indexes manage |
| Backup & Recovery | Regular backup, disaster recovery |
| Integrity & Consistency | Constraints, triggers, ACID maintain karna |
| Upgrades & Patching | Patches lagana, naye version par migrate karna |
| Capacity Planning | Aage ki storage ka andaza |
| Documentation & Automation | Configs likhna, scripts se kaam automate karna |

---

## Types of DBA

| Type | Focus |
|---|---|
| System DBA | Infrastructure, OS-level tuning, patches |
| Database Architect | Schema design, normalization, indexing strategy |
| Application DBA | Kisi specific app (ERP, CRM) ka database, stored procedures |
| Performance / Tuning DBA | Query optimization, bottlenecks |
| Backup & Recovery DBA | Backup (full, incremental, differential), restore, replication |
| Security DBA | Access control, encryption, compliance (GDPR) |
| Cloud DBA | Managed services (AWS RDS, Azure SQL), cost, scaling |

---

## Skills
SQL, DBMS internals, OS basics, scripting (Python/Shell), troubleshooting, security awareness, communication.

---

## Yaad rakhne wali baatein
1. DBA ke 4 main kaam: **security, performance, backup/recovery, integrity.**
2. **Database Architect** design karta hai, **System DBA** infrastructure sambhalta hai.
3. User permissions DCL se: `GRANT` aur `REVOKE`.
